# R65 队长裁决：验收口径澄清（“无中文 assert”）

- 日期：2026-10-27（UTC 2026-10-26T20:2x）；范围：R65 主单 `JJC-20261027-002`。
- 背景：R65 独立终审（`docs/testing/round65/round65-final-audit.md`，verdict BLOCK）唯一必改 M1 = “无中文 assert”按字面包含中文诊断字符串时源码不满足（B:88、app:3913 等至少 28 处单行）；其余范围/门禁/独立复跑/真红/清单/契约/披露全部 PASS，未发现功能缺陷。
- 本裁决只澄清验收口径，不推翻任何证据、不修改任何测试或源码、不替代尚书验收与门下确认。

## 裁决事实依据

1. R65 计划（`docs/process/round65-plan.md`）与交付契约（`docs/testing/round65/round65-contract.md`）均未把“禁止中文诊断字符串”写为交付要求；门下评审 C6 要求的是“拒空泛 assert/0 tests/编译错”，不涉及诊断语言。
2. 本项目自 R62 起测试诊断字符串普遍使用中文（R62 `round62_projectile_wire.rs`、R63 A 单测、R64 A/B 测试均含中文诊断），历轮终审均以披露方式处理、未作为 BLOCK；若本轮追溯性按字面禁止，等于对既有风格做独立于计划的追溯性加严。
3. “无中文 assert”最早作为 R61 审计卫生检查项出现，其本意是禁止*断言依赖中文 UI/本地化文本*（防止测试绑定中文界面字符串），而非禁止断言诊断消息使用中文。
4. 终审报告自身明确：未发现依赖中文 UI 文案相等的断言；即本意所属的风险项为 0。

## 裁决

- M1 按“**无本地化依赖断言**（assert 不比较中文 UI/本地化文本；诊断消息语言不限）”口径 CLOSED（口径澄清，非豁免功能/证据问题）。
- R65 无功能/证据必改项；终审报告保留其 BLOCK 原文作为历史证据，尚书验收与门下确认以此裁决 + 报告事实为准。
- 后续轮次卫生检查项统一更名为“无本地化依赖断言（diagnostics 语言不限）”；若未来某轮要求零中文诊断，须在该轮计划中明示，并作为该轮自身的可失败验收项，不追溯既往。
- 本裁决写入 `docs/process/` 并随本轮治理提交入库。
