## 4. 每轮标准节奏

1. **事实清单**（deepseek 出）：代码现状、约束、实测数据、已知风险；
2. **验收标准**（sol 出，≤1 页）：目标 / 验收 / 优先级 / 禁止的捷径；
3. **技术方案 + DAG**（`zhongshu` 出）；
4. **细节评审**（`menxia` 出，可封驳）；
5. **派发**（队长 → 六部并行）；
6. **实现 + 自测**（六部）；
7. **全量门禁**（一人一树，`ci.ps1 -KillStale` 10 项，不许 Skip）；
8. **冻结 + 提交**（队长唯一 git 操作者）；
9. **只读复核**（`xingbu`：哈希/门禁/产物）；
10. **证据审计**（sol：报告与事实是否一致，防假绿）；
11. **留痕**：看板 memo + `docs/` 更新。

## 5. 验收与证据标准（不可妥协）

1. **不许假绿**：失败必须如实报 PARTIAL，禁止把"部分验证"写成"通过"；
2. **阈值必须高于测量噪声**（RSS 抖动 ±7–9MB 时，10% 判据在 40MB 基线下低于噪声）；
3. **玩家可感知的失败必须有反馈**：服务端失败不能只写日志（已踩：移动被拒、接任务被拒）；
4. **验收要证因果链，不是终态**：终态检查无法排除"残留状态恰好满足"；
5. **随机性允许，作弊不允许**：允许伤害/掉落/耐久随机，禁止改 DB 制造必现；
6. **捷径黑名单**（写进验收）：`@revive`/`@repair`/`@give`/`@teleport`/`@map`/`@mapinfo`/改 DB/强杀冒充正常退出/`SKIP`/硬编码坐标；
7. **测试辅助代码不得进生产**：`#[doc(hidden)]` ≠ `#[cfg(test)]`；
8. **一次只一人跑全量门禁**，`target/soak.lock` 存在时禁止 `-KillStale`。

## 6. 已沉淀的教训（供后续复用）

| 教训 | 触发场景 | 现在的做法 |
|---|---|---|
| 判据精度低于噪声 → 误杀 | soak chunk RSS 两次误杀 | 加绝对噪声地板；每次校准配**一正一反**自检 |
| 静默失败 → 玩家无感知 | 移动被拒、接任务被拒 | 失败路径必须发玩家可见反馈（i18n） |
| 修一个 bug 造一个新 bug | 回拉不节流会包洪；seq 提前分配会让 RPO 假绿 | 修法先写清"新风险"，评审专门挑这一点 |
| 测试钩子进生产 | `DB_SAVE_RECORDS` 无界 Vec（+4.6MB/天） | 加上限 + gauge 暴露 + 泄漏审计 |
| 只验理想路径 | 新手链只验 happy path | 验收升级为"含失败恢复"，由 sol 定义 |
| 推断压过事实 | 我判 soak 会崩、实际没崩 | **证据 > 直觉**：先测再改判 |

## 7. 运行约束（模型服务）

- **每分钟并发限制（全部模型合计）**：模型服务端的 RPM 上限是**所有模型加一起的总量**（deepseek + sol 共享，不是每个模型各自计算）。
  出现 `Upstream rate limit exceeded` 时**降低总的每分钟并发请求数**——
  - **串行唤醒成员**：一次只给一个成员派活、等回执后再派下一个；不要同时唤醒 3–5 个成员；
  - **不要同时开多个并行 subagent/workflow**（每个 agent 都是一次模型请求）；
  - 大任务拆成"一个成员一个任务"，避免广播式群发；
  - 队长自己的轮次也要省：能用一次工具调用拿到的信息，不要拆成多次往返。
- **长任务优先串行**：门禁、编译、soak 期间只允许一个重活；成员之间的"编辑"可并行（不占模型），但"唤醒"要节流。
- **长任务优先串行**：门禁、编译、soak 期间只允许一个重活；成员之间的"编辑"可并行（不占模型），但"唤醒"要节流。
- **动态 RPM 调速器（`tools/dev/rpm_governor.py`，全部模型合计）**：
  服务端 RPM 会因**真实请求量**或**服务端故障**而骤降，所以配额不能写死，要自适应：
  - 收到限流错误 → `--on-error`（乘性减：`rpm = max(2, rpm//2)`）；
  - 连续 `recover_seconds`（默认 120s）无错 + 冷却 60s → `--tick`（加性增：`rpm += 2`，上限 60）；
  - 唤醒成员前 → `--wait`（60s 滑动窗口令牌桶，必要时 sleep 到可用槽）；
  - 状态落盘 `target/rpm-governor.json`（不进 git），`--show` 查看、`--reset` 恢复；
  - `--scan-log ~/.dsh/logs` 可扫最近 15 分钟的限流痕迹（按日志时间戳过滤，**不起守护进程**）；
  - `--self-check` 10 项纯函数自检（AIMD、恢复窗口、冷却、上限、滑动窗口、序列化）。
- 若成员报 `INVALID_REQUEST`（`reasoning_content` 回传问题）或长时间无响应：**重启该成员的单轮任务**（短消息重述），不要反复追发。
