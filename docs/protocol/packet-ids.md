# Crystal 协议：数据包编号总表

> 参照实现：`github\Crystal`（只读）。
> 帧格式与语义见 [framing.md](framing.md)；复杂包体解析见 [packets-complex.md](packets-complex.md)。

## 0. 基础事实

- 两个枚举的底层类型都是 **`short`（有符号 16 位）**：`Shared/Enums.cs:1434`（`public enum ServerPacketIds : short`）、`Shared/Enums.cs:1717`（`public enum ClientPacketIds : short`）。
- 两个枚举**没有任何显式赋值**，全部按 C# 规则从 0 起自增，因此：`ServerPacketIds` = **0 … 278**（279 个成员，无空洞、无重复），`ClientPacketIds` = **0 … 152**（153 个成员，无空洞、无重复）。
- 编号在线上以**小端 2 字节**出现：写 `writer.Write(Index)`（`short` 重载，`Shared/Packet.cs:75`），读 `BitConverter.ToInt16(rawBytes, 2)`（`Shared/Packet.cs:20`）。
- 所有编号都 < 32768，因此有符号 `short` 不会出现负值；Rust 侧用 `i16` 或 `u16` 均可，但**不要**把编号当变长整数。
- 两个方向的编号空间**相互独立**：同一个数值在 Server→Client 与 Client→Server 里含义不同（例如 `0` 分别是 `Connected` 与 `ClientVersion`）。
- 编号 → 解析器的映射由 `Shared/Packet.cs` 里两个手写 `switch` 维护（`GetClientPacket` 从 line 94 起，`GetServerPacket` 从 line 407 起）。凡是枚举里有、`switch` 里没有的编号，接收方会当作“未知编号”并**丢弃整个接收缓冲区**（见 [framing.md](framing.md) 第 4 节）。

## 3. 编号异常与陷阱

### 3.1 枚举成员缺 `switch` 分支（可定义但收不到）

| 方向 | 编号 | 枚举成员 | 后果 |
| --- | --- | --- | --- |
| Server → Client | 47 (`0x002F`) | `RefineCancel` | `Packet.GetServerPacket` 没有该 case → 客户端把它当未知编号，**丢弃整个接收缓冲区**，导致流错位。服务端也没有任何代码 `new S.RefineCancel`，属双向死代码。 |
| Client → Server | 151 (`0x0097`) | `PurchaseGuildTerritory` | `Packet.GetClientPacket` 没有该 case → 服务端把它当未知编号并**丢弃整个接收缓冲区**。但客户端确实会发送它（`Client/MirScenes/Dialogs/GuildTerritoryDialog .cs:190`），服务端也写了处理分支（`Server/MirNetwork/MirConnection.cs:748`）——那个分支永远不可能被触发。 |

### 3.2 枚举成员名与类名不一致

| 方向 | 枚举成员 | 实际 Packet 类 | 说明 |
| --- | --- | --- | --- |
| Server → Client | `WorldMapSetup` | `WorldMapSetupInfo` | 编号 19，线上标识以枚举成员为准。 |
| Server → Client | `ObjectNpc` | `ObjectNPC` | 编号 92，仅大小写差异。 |
| Client → Server | `DellMember` | `DelMember` | 编号 62，枚举里拼写为 `Dell`（双 l）。 |

### 3.3 其它

- 两个枚举都**没有**重复值，也没有空洞；不存在同一数值对应多个成员的情况。
- `ServerPacketIds` 末尾追加过若干成员（`GroupMembersMap`、`SendMemberLocation`、`GuildTerritoryPage`、`StorageUnlockResult`、`StoragePasswordResult`），因此这些编号靠后，而对应类分散写在源文件各处——**编号与源码顺序无关**，只能按值查表。
- `ClientPacketIds` 末尾是 `PurchaseGuildTerritory`、`DeleteItem`、`UnlockStorage`、`SetStoragePassword`、`RemoveStoragePassword`，共 153 个成员。
